## 从源码构建

<details>
<summary>构建命令</summary>

```bash
flutter pub get
flutter run

# 构建 Release
flutter build windows --release

# 或使用项目自带构建脚本（自动清理、更新版本号、输出到 output/）
.\build_windows.ps1
```

</details>
